# NYSC-Hub

A web platform for the full NYSC corper lifecycle — prospective applicants, currently serving corpers, and ex-corpers.

Three cores, shipping together from day one:

- **Info hub** — camp document requirements, fees, travel + camp locations, relocation
- **Community** — ask, share, and connect across batches, states, and generations of corpers
- **Camp workspaces** — per-camp announcements, info boards, food timetables, media/OBS, competitions + voting
